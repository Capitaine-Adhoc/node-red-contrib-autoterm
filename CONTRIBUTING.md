# Contributing

Contributions are welcome. Please submit changes under GPL-2.0-or-later and preserve SPDX headers. Do not infer undocumented protocol meanings: provide captures and mark uncertain bytes as unknown. Include tests for CRC, framing, decoding and serial-proxy event behavior; hardware access must remain optional in tests. Run `npm ci && npm test` before submitting.

Thank's you.
